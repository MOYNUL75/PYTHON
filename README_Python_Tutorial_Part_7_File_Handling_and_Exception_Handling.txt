# Python Tutorial — Part 7: File Handling and Exception Handling

## Included notebook
`Python_Tutorial_Part_7_File_Handling_and_Exception_Handling.ipynb`

## Topics
- File modes and text file read/write/append
- Context manager (`with open`)
- File pointers and encoding
- pathlib paths and directories
- CSV read/write with csv module
- JSON read/write with json module
- try, except, else and finally
- Raising exceptions and custom exception classes
- Mini projects, practice questions and solutions

## How to open
1. Install Jupyter if needed: `python -m pip install notebook`
2. Open a terminal in this folder.
3. Run: `jupyter notebook`
4. Open the `.ipynb` file.

Alternatively, upload it to Google Colab or open it in VS Code with Python and Jupyter extensions.

Run one cell at a time using Shift+Enter. The notebook creates practice files in its current working directory. Do not use `w` mode on important files because it overwrites existing content.
