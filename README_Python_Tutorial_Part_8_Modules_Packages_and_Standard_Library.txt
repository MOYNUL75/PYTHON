# Python Tutorial — Part 8: Modules, Packages and Python Standard Library

## Included notebook
`Python_Tutorial_Part_8_Modules_Packages_and_Standard_Library.ipynb`

## Topics
- What modules are and why they are useful
- Importing complete modules and selected functions
- Module aliases with `as`
- Exploring modules with `dir()` and `help()`
- Standard-library modules: math, random, datetime, statistics, os, pathlib and json
- Creating and importing user-defined Python modules
- Creating packages and using `__init__.py`
- Python module search path (`sys.path`)
- Third-party packages and installing with pip
- Mini projects, practice questions and solutions
- Common import errors and troubleshooting

## How to open
1. Install Jupyter if needed: `python -m pip install notebook`
2. Extract this ZIP file.
3. Open a terminal in the extracted folder.
4. Run: `jupyter notebook`
5. Open the `.ipynb` file.

Alternatively, upload the notebook to Google Colab or open it in VS Code with the Python and Jupyter extensions.

Run one cell at a time using Shift+Enter. Some cells create practice files and folders in the notebook's current working directory. Keep this notebook in a practice folder. Do not name your own files `math.py`, `random.py`, `json.py`, or other standard-library module names.

For package installation inside Jupyter, use `%pip install package_name`. In a terminal, use `python -m pip install package_name`.
