Python Tutorial — Part 10: Regular Expressions (RegEx)
CSC5013 Foundation in Computer Programming

FILES
- Python_Tutorial_Part_10_Regular_Expressions.ipynb
- README_Python_Tutorial_Part_10.txt

TOPICS
1. What is RegEx?
2. Python's re module and raw strings
3. search(), match(), fullmatch(), findall(), finditer()
4. Character classes, quantifiers, anchors and word boundaries
5. Capturing and named groups, alternation
6. sub() and split()
7. Flags and re.compile()
8. Greedy versus non-greedy matching and lookaheads
9. Student ID, phone-like and email-like format examples
10. Text extraction, logging, normalization and redaction mini projects
11. Exam-style practice questions with complete solutions

HOW TO RUN
1. Unzip the archive.
2. Open the .ipynb file in Jupyter Notebook, JupyterLab, VS Code or Google Colab.
3. Run a cell with Shift+Enter.
4. Read explanations and predict the outputs before each cell.

JUPYTER INSTALLATION (IF NECESSARY)
  python -m pip install notebook
  jupyter notebook

REQUIREMENTS
- Python 3 with standard-library re module.
- No external Python packages needed for lesson code.

NOTE
Example email and phone patterns are classroom format checks and do not prove real-world validity.
