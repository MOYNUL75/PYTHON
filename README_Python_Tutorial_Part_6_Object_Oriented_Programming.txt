# Python Tutorial — Part 6: Object-Oriented Programming (OOP)

## Included notebook
`Python_Tutorial_Part_6_Object_Oriented_Programming.ipynb`

## Topics
- Classes and objects
- Attributes, methods, __init__, self
- Instance and class attributes
- Instance, class and static methods
- Encapsulation and properties
- Inheritance, super(), overriding and MRO
- Polymorphism, duck typing and abstraction
- Composition and dunder methods
- Mini projects, practice questions and solutions

## How to open
1. Install Jupyter if needed: `python -m pip install notebook`
2. Open a terminal in this folder.
3. Run: `jupyter notebook`
4. Open the `.ipynb` file.

Alternatively, upload it to Google Colab or open it in VS Code with Python and Jupyter extensions.

Run one cell at a time using Shift+Enter. Change sample values and rebuild the mini projects yourself.
