# Python Tutorial — Part 3: Strings and Collections

## Included notebook
`Python_Tutorial_Part_3_Strings_and_Collections.ipynb`

## Topics
- Strings: indexing, slicing, methods, formatting
- Lists: operations, methods, nested lists, comprehensions
- Tuples: indexing, immutability, methods, unpacking
- Sets: unique items and set operations
- Dictionaries: key-value pairs, methods, iteration, nested dictionaries
- Mini projects, practice questions and solutions

## How to open
1. Install Jupyter if needed: `python -m pip install notebook`
2. Open a terminal in this folder.
3. Run: `jupyter notebook`
4. Open the `.ipynb` file.

You can also upload the notebook to Google Colab or open it in VS Code with the Python and Jupyter extensions.

Run one cell at a time using Shift+Enter. Experiment by changing the values.
