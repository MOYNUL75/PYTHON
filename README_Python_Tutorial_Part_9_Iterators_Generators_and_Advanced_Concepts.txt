# Python Tutorial — Part 9: Iterators, Generators and Advanced Python Concepts

## Included notebook
`Python_Tutorial_Part_9_Iterators_Generators_and_Advanced_Concepts.ipynb`

## Topics
- Iteration, iterable and iterator
- `iter()`, `next()` and `StopIteration`
- How a `for` loop uses an iterator
- Creating custom iterator classes with `__iter__()` and `__next__()`
- Generator functions and `yield`
- `return` vs `yield`
- Generator expressions and lazy evaluation
- `yield from`
- `enumerate()`, `zip()`, `map()` and `filter()`
- The `itertools` module: `count()`, `cycle()`, `islice()` and `chain()`
- Basic decorators and `functools.wraps`
- Context managers and the `with` statement
- Mini projects, practice questions, solutions and common mistakes

## How to open
1. Extract this ZIP file.
2. Open a terminal in the extracted folder.
3. Install Jupyter if needed: `python -m pip install notebook`
4. Run: `jupyter notebook`
5. Open the `.ipynb` file.

Alternatively, upload the notebook to Google Colab or open it in VS Code with the Python and Jupyter extensions.

Run one cell at a time using Shift+Enter. Some cells intentionally demonstrate iterator behavior; read the notes before running them.
