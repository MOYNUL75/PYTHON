## Open the notebook
1. Install Jupyter if needed: `python -m pip install notebook`
2. Open a terminal in this folder.
3. Run: `jupyter notebook`
4. Open `Python_Tutorial_Part_2_Decision_Making_and_Loops.ipynb`.

Alternatively, upload the notebook to Google Colab or open it in VS Code with the Python and Jupyter extensions.

Run one cell at a time with Shift+Enter. Be careful with while loops; always ensure the condition can eventually become False.
