# Python Tutorial — Part 4: Functions and Recursion

## Included notebook
`Python_Tutorial_Part_4_Functions_and_Recursion.ipynb`

## Topics
- Built-in and user-defined functions
- Function definition and calling
- Parameters and arguments
- Positional, keyword and default arguments
- Return values and multiple return values
- *args and **kwargs
- Local, global and enclosing scope
- Docstrings
- Lambda functions
- map(), filter(), sorting with lambda
- Recursion: base cases, factorial, countdown, sum, Fibonacci
- Mini projects, practice questions and solutions

## Open
1. Install Jupyter if needed: `python -m pip install notebook`
2. Open a terminal in this folder.
3. Run: `jupyter notebook`
4. Open the `.ipynb` file.

Alternatively, upload the notebook to Google Colab or open it in VS Code with the Python and Jupyter extensions.

Run one cell at a time using Shift+Enter. For recursion, trace the function calls and returns carefully.
