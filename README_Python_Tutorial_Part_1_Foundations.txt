# Python Tutorial — Part 1: Foundations

## Files
- `Python_Tutorial_Part_1_Foundations.ipynb` — detailed beginner lesson with explanations, runnable code, mini-projects and exercises.

## How to open
### Jupyter Notebook
1. Install Python.
2. Open Command Prompt / Anaconda Prompt.
3. Install Jupyter if needed: `python -m pip install notebook`
4. Go to the folder containing the notebook.
5. Run: `jupyter notebook`
6. Open `Python_Tutorial_Part_1_Foundations.ipynb`.

### JupyterLab
Install if needed: `python -m pip install jupyterlab`
Launch: `jupyter lab`

### Google Colab
Open Google Colab, choose Upload notebook, and upload the `.ipynb` file.

### VS Code
Install the Python and Jupyter extensions, then open the `.ipynb` file.

## Learning instruction
Run one cell at a time using Shift+Enter. Change the values and experiment. Do not only read the code—type, run, observe and practise.
